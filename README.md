## Описание 
Пользователь заполняет две анкеты: для мужчины и женщины. Дальше отвечает на 10 вопросов на тему отношений. После отправки данных модель, анализирует характеристики пары и рассчитывает вероятность долгосрочных отношений. Сервис отображает процент совместимости и прогноз вероятности длительных отношений.

## Как запускать 
Установите все нужные библиотеки из файла requirement.txt при помощи команды pip install requirement.txt.

Запустите сервер локально при помощи команды
```
 uvicorn main.py:app --reload
 ```
